Streamlit × Gemini API で作る AIライティングツール
— app.py のコードを読み解く

0 このファイルの役割

app.py はアプリの画面と操作のすべてを担うメインファイルです。 ユーザーがブラウザで見るUI、ボタンを押したときの動作、AIへの指示の受け渡しまで、ここに集約されています。

1 必要なものを読み込む（インポート）

import streamlit as st
from tools.blog_writer import write_blog
from tools.email_reply import generate_email_reply
...
  • streamlit — 画面を作るライブラリ。st.button() や st.text_input() でUIパーツを置けます
  • tools/ 以下の各ファイル — ツールごとのAI処理ロジック。app.py はUIだけ担当し、AI処理は各ツールファイルに分離されています

2 ページの基本設定

st.set_page_config(
    page_title="AI ライティングツール",
    page_icon="✍️",
    layout="wide",
)

ブラウザのタブに表示されるタイトルやアイコン、レイアウトをここで設定します。layout="wide" で画面幅いっぱいに使えます。

3 ツール一覧の定義

TOOLS = {
    "📝 ブログ記事作成": "blog",
    "📧 メール返信文生成": "email",
    "📋 文章要約": "summary",
    ...
}

サイドバーに表示するツール名（日本語）と内部的なキーの対応表です。新しいツールを追加するときはここに1行足すだけです。

4 サイドバー（左のメニュー）

with st.sidebar:
    selected_label = st.radio("ツールを選択", list(TOOLS.keys()))

st.sidebar ブロックの中に書いたものは左側のパネルに表示されます。 st.radio() でラジオボタンを作り、ユーザーが選んだツール名を selected_label に受け取ります。

5 ツールの切り替え（画面の分岐）

tool = TOOLS[selected_label]  # 例: "blog"

if tool == "blog":
    # ブログ記事作成の画面
elif tool == "email":
    # メール返信の画面
elif tool == "summary":
    # 要約の画面
...

Streamlit はボタンを押すたびにスクリプト全体を上から再実行します。 そのため、選ばれたツールに応じた if/elif で表示する画面を切り替えています。 ページ遷移の仕組みが不要な、Streamlit らしいシンプルな設計です。

6 各ツール画面の構造（ブログ記事を例に）

if tool == "blog":
    # ① 入力欄
    topic = st.text_input("記事のテーマ")
    tone  = st.selectbox("文体", ["フレンドリー", "丁寧", ...])

    # ② ボタン（topicが空なら押せない）
    if st.button("記事を生成する", disabled=not topic):

        # ③ AI処理
        with st.spinner("生成中..."):
            result = write_blog(topic, tone, ...)

        # ④ 結果表示
        st.markdown(result)
        st.download_button("ダウンロード", result)

どのツールも ①入力 → ②ボタン → ③AI処理 → ④結果表示 という同じ流れで作られています。 st.spinner() は処理中にくるくるアニメーションを出す仕組みです。

7 AI処理の流れ全体像

app.py （UI）
↓ ユーザーの入力を渡す
tools/blog_writer.py （プロンプトを組み立てる）
↓
utils/gemini_client.py （Gemini API を呼び出す）
↓
Gemini （テキスト生成）
↓
app.py （結果を画面に表示）

app.py は受付窓口、tools/ は作業指示書の作成、 gemini_client.py はAIへの電話係という役割分担になっています。
